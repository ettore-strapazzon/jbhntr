# Skills — mandatory for every agent

Every agent works at the best of its ability by using the most effective skills available. This is not optional.

## The rule
1. **Check the live skill list before every task.** The available skills change between sessions — never work from memory of what existed; read what is offered *now*.
2. **Invoke every skill that matches the task** with the Skill tool, before and during the work (a skill loads instructions you then follow — it is not a label). If two skills overlap, use the more specific one.
3. **If a capability needs a connector/MCP that isn't authorised**, don't fake it — file a one-line request for the Founder to authorise it (`REQUESTS.md`) and proceed with what is available.
4. **End every deliverable with two lines:** `Skills used: …` and `Skills considered but not used: … (why)`. The CEO rejects a deliverable that ignored an obviously-matching skill.
5. **Found a reusable workflow or a gap no skill covers?** Say so in your report so the CEO can note it; don't silently reinvent it each cycle.
