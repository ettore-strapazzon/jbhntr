# Brand accounts — setup pack (R1-07)

Owner: CMO · Created 2026-10-25 · Source: GTM manual §3.2–3.4 (voice, accounts, "who are you?"), CHARTER guardrail 1.

**Why this doc exists.** Step 2 of the GTM needs brand accounts live before any community work. Agents cannot create accounts (CHARTER guardrail 1), so this pack is two things: (1) the exact handle, bio, profile/banner, and cadence for every platform, ready to paste; (2) a self-contained **REQUEST** block the Founder runs once to create them all.

**Brand voice (binding, GTM §3.2).** Plural — "we / the JBHNTR team". Never claim a team of people that doesn't exist: say "a small, founder-led project". Never put the Founder forward on any brand surface. Disclose "we build a tool in this space" wherever the product is mentioned in a community. No emojis, no hype.

**The product in one line (reuse everywhere):** *JBHNTR reads every live role for a mid-senior professional and returns the 10–20 worth pursuing, with a two-way fit score and the reasons for and against. Never auto-apply.*

**Tagline (from the match card):** *Less searching. Fewer applications. Better matches.*

**The "who are you?" paragraph (GTM §3.4 — verbatim, use in every FAQ/thread and as the long-form bio):**
> JBHNTR is a small, founder-led project built in Europe, currently in private beta. The product shell is source-available on GitHub (github.com/jbhntr/jbhntr) and credits who built it; the matching engine is private. We market as a brand rather than a person by choice. Everything about how matching works, what data we keep and what we refuse to do is on the site — ask us anything about it.

## 3. REQUEST block for the Founder (agents cannot create accounts)

> **REQUEST: Create the JBHNTR brand accounts (one sitting, ~60–90 min)**
>
> Before you start: have the avatar (1024×1024 wordmark PNG) and banner image to hand, and the product domain `jbhntr.app` email set up (at least `hello@`). Bio text to paste for each platform is in `company/docs/marketing/BRAND_ACCOUNTS.md §1`. Use the plural "we / the JBHNTR team" voice; put your own name nowhere on these surfaces.
>
> 1. **Email aliases first.** In your domain/email provider, create mailboxes or aliases `hello@jbhntr.app`, `research@jbhntr.app`, `partners@jbhntr.app`, and `privacy@jbhntr.app`. These are needed by the steps below. Set the signature to "— The JBHNTR team / jbhntr.app".
> 2. **GitHub org `jbhntr`.** Create a free GitHub organisation named `jbhntr`. Set the org email to `hello@jbhntr.app`, website `jbhntr.app`, avatar = wordmark, and paste the org description from §1. (The repos themselves are handled by the repo-split plan — this step is just the org shell.)
> 3. **X `@jbhntr`.** Create the account with email `hello@jbhntr.app`. Paste the X bio from §1, set location "Europe", website `jbhntr.app`, upload avatar + banner. Turn off the "who to follow" contacts upload.
> 4. **Bluesky `@jbhntr`.** Create the account (`hello@jbhntr.app`). Paste the Bluesky bio, upload avatar + banner. If quick, verify the `jbhntr.app` domain handle (Settings → Handle → "I have my own domain").
> 5. **Threads `@jbhntr`.** This needs an Instagram login. Create an Instagram account `jbhntr` (`hello@jbhntr.app`) only to hold Threads — do not post to Instagram. Enable Threads, paste the Threads bio, upload avatar.
> 6. **Reddit `u/jbhntr`.** Create the account (`hello@jbhntr.app`). Paste the Reddit bio. Do **not** add a product link to the profile yet — we build two weeks of karma first. One account only.
> 7. **LinkedIn Company Page "JBHNTR".** From your personal LinkedIn, create a Company Page (Work → Create a Company Page → "Small business"). **Set the page admin/contact email to `hello@jbhntr.app`, and do NOT add JBHNTR to your own profile as a job/employer.** Fill: name JBHNTR, `jbhntr.app`, industry "Software Development", size "Myself only", type "Privately held", location Europe; paste the tagline and the About text; upload avatar + banner.
> 8. **Hacker News `jbhntr`.** Create the account at news.ycombinator.com (`hello@jbhntr.app`). Paste the About text. Leave it dormant until launch week — creating it now just ages the account.
>
> **When done, reply with:** the live URL of each account (X, Bluesky, Threads, LinkedIn Page, Reddit, GitHub org, HN), and confirm (a) the LinkedIn Page admin email is `hello@`, not your personal email, and (b) JBHNTR is not listed on your personal profile. Paste this to collect it in one go:
>
> ```
> X: __  Bluesky: __  Threads: __  LinkedIn Page: __  Reddit: __  GitHub org: __  HN: __
> LinkedIn admin email is hello@ (not personal)? y/n: __   JBHNTR absent from my profile? y/n: __
> ```
